# landing-calculator

Одностраничный сайт строительной компании «Полдень» с калькулятором стоимости дома и формой заявки. Фирмы такой нет, цены и контакты на странице условные. Смета собирается по строкам, телефон вводится по маске, а serverless-функция пересылает заявку в Telegram и/или на почту. Код на HTML, CSS и JS без сборки и npm-зависимостей, страница весит 37 КБ в gzip (шрифт Manrope с Google Fonts сюда не входит).

Демо: https://sinnercode228.github.io/portfolio/landing-calculator/

## Смета из округлённых строк

Цены, коэффициенты и сроки лежат в [`js/config.js`](js/config.js), смету по ним считает функция `calculate` в [`js/calc.js`](js/calc.js). Каждая строка сметы округляется отдельно:

```text
цена за м²  = round(цена технологии × коэф. этажности, 10)   коэф.: 1 этаж — 1, 2 этажа — 0.94
коробка     = round(площадь × цена за м², 1000)
отделка     = round(коробка × (множитель − 1), 1000)         shell 1, whitebox 1.3, turnkey 1.65
плита       = round(ceil(площадь / этажи × 1.1 − 1e-9) × 7500, 1000)
терраса     = м² × 12 000
гараж       = 950 000
итог        = сумма строк
```

Итог я не округляю, он складывается из уже округлённых строк, и разбивка всегда сходится с суммой. Тест «сумма строк разбивки всегда равна итогу (перебор комбинаций)» в [`tests/calc.test.js`](tests/calc.test.js) проверяет это на 360 комбинациях (4 технологии × 3 уровня отделки × 2 этажности × 5 площадей × 3 набора опций).

`100 * 1.1` в JS даёт `110.00000000000001`, поэтому в формуле плиты стоит `− 1e-9`. Без поправки `Math.ceil` насчитал бы дому 100 м² в один этаж 111 м² плиты и 833 000 ₽ вместо 825 000. Площадь целая, этажей один или два, так что у точного значения дробная часть либо ноль, либо не меньше 0,05, и поправка её не задевает.

По умолчанию (газобетон, 120 м², один этаж, white box, плита) выходит 3 720 000 + 1 116 000 + 990 000 = 5 826 000 ₽, как на скриншоте. Это же число проверяет первый тест в `calc.test.js`.

## Ссылка на расчёт

Кнопка «Скопировать ссылку на расчёт» пишет 7 параметров калькулятора в адрес через `history.replaceState`, а при открытии такой ссылки `decodeState` пропускает их через ту же `normalizeInput`, что и ввод с формы. Значения `tech`, `finish` и `floors` ищутся в конфиге через `hasOwnProperty`, поэтому `?tech=__proto__` даёт газобетон по умолчанию, а простая проверка `cfg.technologies[tech]` пропустила бы такой ключ (по нему лежит `Object.prototype`), и `calculate` упал бы с TypeError.

## Форма и serverless-обработчик

Маска `+7 (___) ___-__-__` собрана из чистых функций в [`js/form-utils.js`](js/form-utils.js). Ведущая 8 становится 7, курсор при правке в середине номера не прыгает в конец, а Backspace сразу за скобкой, пробелом или дефисом стирает ближайшую цифру слева. В демо `leadEndpoint` в `config.js` пустой, и заявка никуда не уходит; экран успеха показывается как обычно, а JSON заявки печатается в консоль браузера.

Заявки принимает [`serverless/telegram-lead.mjs`](serverless/telegram-lead.mjs), функция `handleLead(request, env)` на Web Fetch API. Запрос с телом длиннее 20 000 символов получает 413 ещё до `JSON.parse`. Если заполнено скрытое поле-ловушка `website`, спам-бот получает 200 `{ ok: true }`, но в Telegram и на почту ничего не уходит. Телефон сервер проверяет заново по `^\+7\d{10}$`, имя и комментарий по длине, при ошибке отвечает 422.

Телефон в сообщение берётся из проверенного `phone`, а не из клиентского `phoneFormatted`. Сообщение уходит с `parse_mode: 'HTML'`, поэтому поля проходят через `escapeHtml`, а обрезаются ещё до экранирования, потому что лимит в 4096 символов Telegram считает по тексту после разбора HTML-сущностей. Telegram и письмо в Resend уходят параллельно (`Promise.allSettled`), и 502 возвращается, только если не дошёл ни один канал.

### Подключение заявок

Адрес развёрнутого обработчика пишется в `leadEndpoint` в [`js/config.js`](js/config.js). На Cloudflare Workers файл работает как есть через `export default { fetch }`, для Vercel и Netlify нужна обёртка, которая передаёт запросы `POST` и `OPTIONS` в `handleLead(req, process.env)`. Telegram включается переменными `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, почта через Resend — `RESEND_API_KEY` и `LEAD_EMAIL_TO` (отправитель в `LEAD_EMAIL_FROM`). `ALLOWED_ORIGIN` уходит в CORS-заголовок. Если не задан ни один канал, обработчик отвечает 500.

Чего нет: ограничения частоты запросов (от спама защищает только ловушка `website`) и пересчёта сметы на сервере, так что `calculation.summary` после обрезки и экранирования уходит в Telegram в том виде, в каком его прислал клиент. `ALLOWED_ORIGIN` по умолчанию `*`, для настоящего сайта его надо задать.

## UMD и тесты в Node

Скрипты подключены обычными `<script defer>`, и `index.html` открывается двойным кликом. `config.js`, `calc.js` и `form-utils.js` написаны как UMD и в браузере кладут объект в `window` (`HOUSE_CONFIG`, `HouseCalc`, `FormUtils`), а в Node отдаются через `module.exports`. Тесты делают `require()` тех же файлов, что грузит страница, без jsdom и браузера. Обработчику заявок тесты передают подменённый `fetch` третьим аргументом, и в сеть ничего не уходит.

`app.js` связывает чистые функции со страницей, его поведение (обработчики, анимация, фокус) тестами не покрыто. [`tests/page.test.js`](tests/page.test.js) читает `index.html` и `app.js` как текст и проверяет регулярками, что id не повторяются, файлы из `src`/`href` существуют, у полей есть подписи, а подписи карточек проектов совпадают с их пресетами. Ещё один тест там же следит, чтобы HTML, CSS, JS и favicon вместе весили меньше 50 КБ в gzip.

Всего 49 тестов на встроенном `node:test`: 14 на расчёт ([`tests/calc.test.js`](tests/calc.test.js)), 9 на маску и форму ([`tests/form-utils.test.js`](tests/form-utils.test.js)), 13 на обработчик ([`tests/serverless.test.mjs`](tests/serverless.test.mjs)), 11 на разметку ([`tests/page.test.js`](tests/page.test.js)) и 2 на dev-сервер ([`tests/serve.test.mjs`](tests/serve.test.mjs)).

## Доступность

Итог дублируется в скрытый элемент с `aria-live="polite"` через 700 мс после последнего изменения, чтобы скринридер не зачитывал каждый шаг ползунка, а у самого ползунка площади `aria-valuetext` со склонением («120 квадратных метров»). При `prefers-reduced-motion` анимации и переходы сводятся к 0,01 мс, и сумма обновляется сразу, без отсчёта цифр.

## Локальный запуск

```bash
# без Node: открыть index.html в браузере
npm start            # dev-сервер на node:http, http://localhost:8080
npm start -- 3000    # другой порт
npm test             # Node ≥ 22, зависимостей нет
```
