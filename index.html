Zernolist

Магазин кофе и чая, который открывается прямо в Telegram: каталог с поиском, промокоды, курьер или самовывоз, оплата в Telegram Stars или при получении. Заказы приходят админу в бот, статус он меняет кнопками под уведомлением.

The server prices every order from the catalog itself, so nobody can change the price in the browser. If Telegram sends the same payment update twice, the order goes through only once.
