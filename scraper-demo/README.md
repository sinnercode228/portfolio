# bookscraper

Асинхронный CLI-парсер для [books.toscrape.com](https://books.toscrape.com), песочницы для практики скрапинга. Разбор HTML короткий, основная часть кода — сетевой слой и чистка данных: лимит запросов в секунду, повторы с `Retry-After`, дисковый кэш, срезание дублирующегося тизера в описаниях. Результат уходит в XLSX, CSV и JSON. Написан на Python 3.10+ (asyncio, httpx, selectolax, openpyxl); gspread ставится отдельно и импортируется только при `--gsheet`.

```bash
git clone https://github.com/sinnercode228/portfolio.git
cd portfolio/scraper-demo
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bookscraper --limit 100 --out output/books    # books.xlsx + books.csv + books.json
```

Файлы `books_sample.*` в [`output/`](output/) получены такой командой (время и уровень в логе убраны):

```
$ python -m bookscraper --limit 100 -o output/books_sample.xlsx -o output/books_sample.csv -o output/books_sample.json
...
  Travel                   11 product links
  Mystery                  32 product links
  Historical Fiction       26 product links
  Sequential Art           31 product links
...
scraped 100 books in 30.3s — 109 HTTP requests, 0 cache hits, 0 retries, 0 errors
```

![Лист Books из output/books_sample.xlsx](docs/excel_preview.jpg)

С карточки снимается 16 полей, в JSON идут все, в XLSX и CSV 11. Кроме листа Books в файле есть Summary (статистика по категориям и строка TOTAL) и About (источник, время, параметры запуска, число ошибок). [`exporters/excel.py`](bookscraper/exporters/excel.py) оставляет текстом значение на `=`, даже если openpyxl принял его за формулу. `test_xlsx_keeps_formula_like_text_as_text` выгружает запись с названием `=HYPERLINK("http://evil.test")`, открывает xlsx через `load_workbook` и проверяет `data_type == "s"`.

## 109 запросов за 30 секунд

109 запросов складываются из robots.txt, главной, 7 страниц листинга и 100 карточек, а время прогона задаёт лимитер. `RateLimiter` в [`fetcher.py`](bookscraper/fetcher.py) хранит момент следующего разрешённого старта: задача под `asyncio.Lock` спит до него и сдвигает его на `1/rate`. Запаса, как в token bucket, здесь нет, поэтому нет и всплеска на старте. При `--rate 4` старты идут через 0,25 с, и 108 интервалов между 109 стартами дают 27 с при любой скорости сети.

`wait()` лимитера вызывается внутри семафора, прямо перед `client.get`. Если вызвать его до входа в семафор, задача получит время старта, постоит в очереди за соединением, и несколько таких задач уйдут в сеть разом. Перед повтором задача спит вне семафора, чтобы запрос, который ждёт до 30 с, не занимал одно из пяти мест (`--concurrency 5`).

Повтор запускают ответы 408, 425, 429, 500, 502, 503 и 504, а ещё таймауты и сетевые ошибки. По умолчанию повторов до трёх, и каждый заново проходит семафор и лимитер. На 404, 501 и прочих кодах сразу летит `FetchError`. Пауза `min(30, 0.5·2^(n-1))` с equal jitter даёт 0,25–0,5 с перед первым повтором и 1–2 с перед третьим. `Retry-After` в секундах или HTTP-дате может её удлинить, но потолок остаётся 30 с, и при `Retry-After: 120` повтор уйдёт раньше срока. Ошибка на одной карточке, даже неожиданная, попадает в список в конце лога, а [`crawler.py`](bookscraper/crawler.py) продолжает прогон.

## Кэш, который переживает `kill -9`

[`cache.py`](bookscraper/cache.py) хранит ответ в `.cache/http/<первые 2 символа хэша>/<sha256 от URL>.json` вместе с URL и временем записи. Кэшируются только ответы 200, срок жизни 24 ч (`--cache-ttl 0` делает его бессрочным), при чтении сверяется сохранённый URL, битый JSON считается промахом. Попадание возвращается до семафора и лимитера, так что страницы из кэша не ждут своих 0,25 с.

Запись идёт во временный файл с pid и id потока в имени и заканчивается `os.replace`, поэтому недописанного `<sha256>.json` не бывает даже после `kill -9`. После Ctrl-C XLSX, CSV и JSON не пишутся, но кэш пополняется после каждой страницы, и повторный запуск уже скачанное заново не качает. Если запись в кэш упала с `OSError` (например, кончился диск), в лог уходит warning, а страница всё равно идёт в парсер.

## Тизер в начале описания

Длинное описание на сайте приходит как `<тизер, обрезанный посреди слова> <полный текст> ...more`. `clean_description` в [`parsers.py`](bookscraper/parsers.py) срезает тизер, только если в конце стоит `...more`. Без маркера повтор в начале считается обычным текстом, и `test_clean_description_needs_more_marker_to_cut` проверяет, что «Rise and shine, little one. Rise and shine, little one, the sun is up.» остаётся как есть.

Сам срез ищет следующее вхождение первых 20 непробельных символов и режет, если общий префикс тизера и остатка не короче половины тизера (порог в половину, чтобы пережить битый символ). Эти 20 символов могут встретиться и внутри самого тизера, тогда поиск переходит к следующему вхождению (`test_clean_description_opening_words_repeated_inside_teaser`).

## Тесты

80 тестов, все офлайн. Сохранённые страницы лежат в `tests/fixtures/`, и `httpx.MockTransport` из [`tests/conftest.py`](tests/conftest.py) раздаёт их как копию сайта, вплоть до 404 на robots.txt и ответов без charset. Вместо gspread подставлен фейковый модуль. На парсеры 34 теста, на сетевой слой 18 (повторы, `Retry-After`, TTL, сбой записи кэша, лимитер, семафор), на экспорт 9, на обход сайта 8, на `main()` целиком 7 и на Google Sheets 4.

```bash
pip install -r requirements-dev.txt
python -m pytest -q
ruff check .
```

## Флаги и коды выхода

Все флаги печатает `python -m bookscraper --help`, чаще всего нужны эти:

| Флаг | По умолчанию | Что делает |
|---|---|---|
| `-c, --category NAME` | все | категория по имени или slug без учёта регистра, можно повторять; список даёт `--list-categories` |
| `-n, --limit N` | без лимита | максимум книг |
| `-o, --out PATH` | `output/books` | формат по расширению, без расширения пишутся все три; можно повторять |
| `--csv-sep` | `comma` | разделитель CSV: `semicolon` для Excel с русской локалью (цены тогда с десятичной запятой) или `tab` |
| `--rate RPS` / `--concurrency N` | 4 / 5 | запросов в секунду (`0` без лимита) / одновременных запросов |
| `--gsheet KEY_OR_URL` | | ещё и в Google Sheets: `pip install -r requirements-gsheets.txt`, ключ сервисного аккаунта в `--gsheet-creds`, таблицу надо открыть на e-mail аккаунта |

Коды выхода: `0` готово (упавшие страницы только перечисляются в логе), `1` ничего не собрано, `2` неверные аргументы или неизвестная категория, `3` главная не скачалась или закрыта в robots.txt, `4` ошибка Google Sheets, `5` не удалось записать файл (например, он открыт в Excel на Windows), `130` Ctrl-C.

Если robots.txt ответил 5xx или не ответил вовсе, парсер считает, что можно всё, как при 404, хотя RFC 9309 в этом случае велит считать закрытым весь сайт.
